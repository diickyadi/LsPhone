# LS Phone - Website Penjualan Smartphone

LS Phone merupakan website penjualan smartphone berbasis Laravel yang menyediakan informasi produk, katalog smartphone, dan pengelolaan konten melalui dashboard admin.

## Fitur

* Katalog produk smartphone
* Pencarian produk
* Informasi dan promosi produk
* Testimoni pelanggan
* Dashboard admin untuk mengelola konten dan produk

## Teknologi

* Laravel
* PHP
* MySQL
* HTML, CSS, dan JavaScript

## Instalasi

1. Clone repository ini.
2. Masuk ke folder project.
3. Install dependency menggunakan Composer.
4. Salin `.env.example` menjadi `.env`.
5. Sesuaikan konfigurasi database.
6. Jalankan migrasi database jika diperlukan.
7. Jalankan aplikasi Laravel.

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Catatan: Sesuaikan langkah instalasi dengan konfigurasi dan kebutuhan project.
